About & Privacy

LAN Clipboard
Version 1.0.0 — Client-side only

A privacy-focused application for sharing text between trusted devices on your local network. No cloud required. No account. No tracking.

Your clipboard data is stored locally on this device.

Clipboard history is stored in your browser's IndexedDB — not on any server. Clipboard transfers are sent directly between trusted devices using WebRTC DataChannels. No clipboard content is sent to an external server.

How peer-to-peer connections work

LAN Clipboard uses WebRTC to create a direct, encrypted connection between devices. Pairing information (connection setup) is exchanged manually via QR code or copy/paste — it never passes through a cloud server. After pairing, clipboard content travels directly between your devices.

Browser Limitations

Due to browser security restrictions:

  • Clipboard access requires a secure context (HTTPS or localhost).
  • Automatic clipboard monitoring is not possible without user action.
  • Camera access for QR scanning requires your permission.
  • WebRTC requires the browser to support RTCPeerConnection.
